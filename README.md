# LoLPing Mac 1.9.1 · 服务器联机版

在 Mac 桌面发送和接收 Ping。支持同一 Wi-Fi 的局域网直连，以及不同网络之间的服务器房间联机。

客户端保留局域网直连，并提供加密的 WebSocket 房间中继。客户端要求 macOS 13 或更新版本，安装包同时支持 Apple 芯片和 Intel。

## 应用内更新

1.6.0 起支持自动检查和一键更新。控制窗口底部“软件更新”和菜单栏都提供入口；默认启动时及每小时检查新版本，发现更新后在应用内提醒。点击“立即更新至…”后下载、校验、安装并重启，无需手动下载、解压或拖入应用程序目录。“自动检查更新”开关会保存选择，不会在后台强制安装或重启。

更新源由本仓库发布，更新列表及安装包使用独立 Ed25519 签名，App 内置公开验证密钥。个人设置和自定义表情保留；1.9.0 起保存房间凭证，更新重启后自动恢复原房间。macOS 可能要求管理员确认或重新允许辅助功能。

1.5.1 及以前没有更新器，首次安装 1.6.0 完整包后才可使用应用内更新。维护者发布流程见 [updates/README.md](updates/README.md)。

## 程序坞入口

1.9.1 起，运行 LoLPing 时会显示程序坞图标，点击图标可打开或恢复控制窗口。关闭窗口后信号与联机继续运行，菜单栏入口也保留。右键程序坞图标 → 选项 → 在程序坞中保留，可在退出后继续保留启动入口；按 Command + Q 或选择“退出 LoLPing”才会退出程序。

## 房间码粘贴

1.5.1 补齐 macOS 标准编辑菜单，输入框支持 Command + V 粘贴、Command + C 复制、Command + X 剪切、Command + A 全选及撤销/重做。服务器和局域网房间码旁均提供“粘贴”按钮；服务器按钮接受复制的分组房间码，自动忽略空格、换行和连字符、统一大写。无效或空剪贴板会提示并保留原输入，粘贴不会自动加入或离开房间。联机时房间码也可编辑，粘贴另一个房间码后点击“切换房间”才生效；格式错误不会断开当前连接。

## 统一轮盘与自定义图片

信号和表情共用一个轮盘及一套快捷键。外围 8 格与中心格都可替换为任意信号、内置表情、自己的图片或留空。先点击轮盘上的格子，再点击下方内容即可替换并自动保存，也可将内容拖到对应格子。“清空这个格子”停止该位置发送，“恢复默认轮盘”恢复九种信号，不删除图片库。

内置 [darrenprx/lolPing](https://github.com/darrenprx/lolPing) 的全部 44 张 PNG 表情，包括魄罗、猫咪和小蜜蜂，离线即可选择，不占自定义图片名额。来源、固定版本与素材声明见 `Resources/Emotes/NOTICE.txt` 和 `catalog.json`；图片素材归 Riot Games 所有。

点击“添加图片…”或拖入 PNG/JPG/GIF/WebP，可保存最多 24 张自己的图片，单张原图不超过 8 MB，最长边不超过 8192 像素。GIF/WebP 使用首帧，导入后保留透明背景并自动缩放为最长边 160 像素、32 KB 以内的 PNG；第一张成功导入的图片替换当前格子。自己的图片支持重命名、删除、试用和发送。

开启“启用信号”后，默认按住 Control + Option + Command，移动选择并松开发送当前格子的内容。沿用原信号快捷键，旧表情格子的图片自动迁入统一轮盘，不再需要独立表情开关或组合键。图片与轮盘保存在 `~/Library/Application Support/LoLPing/Emotes`，安装更新保留个人设置。

服务器与局域网均可传图片，朋友无需预先导入；图片接收需使用 1.5.0 或更新版本，编辑统一轮盘需 1.7.0。收到的图片只用于当前效果，不加入个人库、不写入磁盘。每秒最多发送一张图片，显示约 3 秒。

## 服务器公共图片库

1.8.0 起可把自己的图片存到服务器，所有连接同一服务器的用户都能浏览、下载并放入轮盘。开启“服务器联机”后点击轮盘中的“公共图片库…”，无需创建或加入信号房间。

先在“添加图片…”中导入自己的图片；在公共库选择“我的图片”并点击“上传到公共库”，或右键个人图片选择上传。只上传用户主动选择的图片，不自动公开个人库、快捷键或轮盘配置。公共库使用当前服务器联机昵称显示上传者，昵称是显示标签。

选择一个轮盘格子后进入公共库，点击“保存并放入格子”，保存到个人图片库并自动替换该格子，以后离线也能使用。相同图片按 SHA-256 去重，不占重复名额。上传者在原上传客户端可点击“从公共库删除”；删除只影响服务器公共副本，自己和其他用户已保存的图片保留。删除凭证在本机保存并按服务器区分，重新安装应用会保留；换电脑不会自动取得原上传的删除权限。

公共库默认最多 500 张，每张为最长边 160 像素、32 KB 以内的 PNG；每个来源地址每分钟最多 12 次上传。图片和索引保存在 Docker 持久卷 `lolping_gallery_data`，服务或容器重启后保留。部署详见 [relay/README.md](relay/README.md)。本机个人图片名额仍为 24 张，44 张内置表情不占名额。

## 当前服务器

已部署的服务器地址为 `wss://18.236.249.217:28787/ws`。1.9.1 客户端已预填这个地址，并内置该服务器专用的公开根证书。只需 TCP 28787，不需要额外开放证书签发端口，也不需要安装系统根证书。

双方使用 1.9.1 安装包，打开“服务器联机”开关，一人创建房间，另一人填 12 位房间码加入。该私有证书信任只对内置的服务器 IP 与端口生效，仍验证证书链、IP 地址和有效期；其他服务器沿用系统 HTTPS 校验。

## 跨网络联机

1. 先按 [服务器部署说明](relay/README.md) 部署中继。
2. 双方安装 **1.9.1 服务器联机版**，打开“服务器联机”开关，填写相同的服务器地址，例如 `wss://ping.example.com/ws`，并填写各自昵称。
3. 一人点击“创建房间”，将 12 位房间码分享给朋友；另一人输入房间码后点击“加入房间”。
4. 显示“已连接：朋友的名字”后，点击“发送测试信号”检查连接。
5. 使用快捷键发送时，开启“启用信号”并允许辅助功能，默认按住 Control + Option + Command，移动选择信号后松开；也可点击“轮盘快捷键”旁的“自定义…”修改。

1.9.0 起，信号和表情都按发送者鼠标落点在发送屏幕中的相对坐标转发，显示在接收者鼠标所在屏幕的对应位置，并带上发送者名字。双方分辨率不同时按比例映射，支持负坐标、上下排列及不同尺寸的显示器；不传送屏幕画面。双方需更新至 1.9.0 才能获得完整位置同步。只接收信号不需要辅助功能权限。“接收朋友信号”和“静音朋友”可分别控制显示与音效；关闭本机全局快捷键 不会关闭接收。

服务器联机和局域网联机开关互斥。关闭服务器联机立即退出房间、清除朋友效果并停止收发和自动重连；重新开启后需创建或加入房间。开关偏好会保存。1.9.0 起，正常退出或应用内更新会保留房间，启动后自动恢复；明确点击“离开房间”、关闭服务器联机或切换至 LAN 会删除当前自动恢复凭证。局域网仍使用原来的 4–8 位房间码和相对屏幕坐标；服务器房间使用中继生成的 12 位房间码。

## 自定义组合键

点击“轮盘快捷键”旁的“自定义…”，直接按下想用的按键，全部松开后自动保存，无需点保存。支持单键、多个普通按键、单独修饰键及组合，包含字母、数字、空格、方向键、F1–F20、小键盘、Esc、Fn、Caps Lock 和能传递给应用的媒体键。支持恢复默认；旧版设置自动保留。信号和表情共用此组合键。

使用时按住所选按键 0.18 秒，移动选择后松开任意一个键发送，先后按下均可。短按不发送，右键取消；未把 Esc 设为触发键时也可用 Esc 取消。重复按键和不同松键顺序只提交一次。设置窗口打开时暂停全局输入，关闭后恢复。建议避开常用打字键和系统快捷键；系统独占或键盘驱动未传递给应用的按键无法录入。

## 服务器部署

服务器使用 Node.js WebSocket 中继，Docker Compose 配套 Caddy 申请 HTTPS 证书。详见 [relay/README.md](relay/README.md)。服务器运行中继，桌面动画与音效由两台 Mac 本地显示、播放。

```sh
cd relay
cp .env.example .env
# 将 .env 中的 PING_DOMAIN 修改成已解析到服务器的真实域名。
docker compose up -d --build
```

已有 Nginx/Caddy 的服务器使用 `compose.proxy.yaml`，中继只绑定服务器的 `127.0.0.1:8787`，不会抢占 80/443。

## 构建与验证

Mac 客户端需要 Swift 命令行工具。服务器需要 Node.js 22 或更新版本，Docker 镜像使用 Node.js 24。

```sh
zsh scripts/test.sh       # 手势、局域网和服务器协议检查
zsh scripts/build.sh      # 构建 dist/LoLPing.app
cd relay
npm ci --ignore-scripts
npm test                 # 中继服务测试
npm run test:swift       # 真实生产版 Swift 客户端集成检查
# 从仓库根目录检查联机开关和按键路由（仅创建临时测试房间）：
# dist/LoLPing.app/Contents/MacOS/LoLPing --feature-check wss://18.236.249.217:28787/ws
cd ..
zsh scripts/package.sh   # 通用 App 和 ZIP
zsh scripts/package-installer.sh  # 完整 PKG：固定安装路径、旧版备份和授权引导
```

源码包括 `Sources/LoLPing/RelayClient.swift`、`Sources/PingCore/RelayProtocol.swift` 及整个 `relay/` 目录。网络中转发信号类型、表情图片、事件 ID、发送者及本次信号落点的相对坐标；不持续追踪鼠标，不同步桌面画面或按键内容。启用持久会话目录后，中继将房间和成员凭证哈希写入私有数据卷；服务器重启后仍可恢复。离线成员默认保留 30 天，超过期限需重新加入或创建，断线期间的信号不补播。房间最多两人；未启用持久会话的旧服务器仍按 60 秒保留离线席位。客户端的自动恢复凭证保存在本机钥匙串，按服务器区分，不发布到公共图片库。

### 更新时保留辅助功能权限

1.9.0 起使用固定本地代码签名身份，发布脚本要求相同证书和 bundle ID；不会在发布失败时退回 ad hoc 签名。公钥证书位于 `Resources/Signing/LoLPing-Stable.pem`，私钥仅在维护者本机登录钥匙串中，未打包或上传。源码开发可设置 `LOLPING_ALLOW_ADHOC=1`，该产物不能作为正式更新发布。

从旧 ad hoc 版本首次升级到 1.9.0 后，需要使用者在辅助功能中允许一次当前 `/Applications/LoLPing.app`；后续同一固定签名身份更新可保持身份。系统手动撤销授权、重置隐私数据库或更换签名身份仍可能需要重新允许。缺少权限时 App 会等待，手动允许后自动恢复原开启状态。此证书不是 Apple Developer ID 或公证，不要求其他用户导入或信任证书。
